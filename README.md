# Human Chatbot
_Tuned to mimic a human behaviour when talking_

## How to run:
### Step 1:
#### Install npm dependencies
``` bash
npm install
```
### Step 2:
#### Update the environment variable:
update the OPENROUTER_API_KEY variable in  the environment variable with the API key of any model available </br>
_API key of any model provider can be used_

### Step 3:
#### Start the node server through
``` bash
npm start
```
the server will start at `localhost:8000` by default </br>

You can use Postman or any other testing software to send the `POST` request </br>

Send the question through body text in the request
